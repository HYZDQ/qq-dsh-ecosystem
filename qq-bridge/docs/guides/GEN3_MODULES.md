# 三代仿真模块讲解

> 面向：想知道控制台「三代仿真」页每个模块在干什么、为什么有时“勾了却没反应”的人。
>
> 一句话：**二代（reserved2）决定“怎么收发”，三代决定“该不该说、对谁说、什么时候说、说完记住什么”。**
>
> 本文只讲使用与直觉，不展开实现细节；设计约束见 `docs/design/GEN3_SIMULATION_PLAN.md`。所有例子均为虚构。

---

## 0. 先看整体：一条消息会经过哪些模块

```text
收到消息 / 定时唤醒
  → 注意力：说（speak）/ 等一下（wait）/ 沉默（silent）
  → 人设 + 记忆 + 情感：拼本轮提示词
  → 模型生成
  → 风格：检测 AI 味，必要时轻改一次
  → 节奏：规划气泡数与每条间隔
  → 表情：按语境挑一张，或干脆不发
  → 发送（仍是二代的 confirm / 回读 / 熔断 / 频控）
```

另外三条线是旁路：

- **主动性**：不靠消息触发，定时判断“现在适不适合主动开口”。
- **记忆**：消息处理完后沉淀，凌晨 04:30 做一次巩固。
- **情感**：一直在后台缓慢变化，只轻微调制句长、延迟、表情率、主动概率。

## 1. 基础组：先搞懂四个总开关

这一组不是具体模块，但决定了下面所有模块能不能生效。

| 开关 | 作用 | 你需要注意 |
| --- | --- | --- |
| 启用三代仿真 | 总闸。关掉就完全回二代，参数仍保留 | 关掉后「一键回 V2」即可，随时可切回 |
| 灰度模式 | `shadow` 只记录；`canary` / `on` 仅名单内会话生效 | **`on` 不是全量**，名单为空时 on 也不生效 |
| 记忆只读锁 | 只约束记忆模块：不落盘、不注入、不跑巩固 | shadow 下它本来就是冗余的；canary 时才有意义 |
| canary 群名单 | 三代模块的生效白名单 | 群写 `group:<群号>`，私聊写 `private:<QQ号>`，逗号分隔 |

**和 QQ 白名单的区别**：

- QQ 白名单决定 bot 能不能在这个会话收发消息；
- canary 名单决定消息进来后**用不用三代逻辑**。

两个都要过。例如白名单里有群 A，但 canary 名单为空，群里一切照旧走二代。

**影子（shadow）不是“没运行”**：它仍在每轮计算，并把决策写进
`state/simulation-trace-YYYY-MM-DD.jsonl`，只是不改 QQ 行为。以后评估“说得对不对”就靠这些记录。

> **三代预设**：`dsh/agent-presets/qq-chat-v3` 基于二代 `qq-chat-v2`，工具协议与安全边界完全一致，只补充了一段 V3 模块说明。只有 **canary 名单里的会话**会使用它；名单外仍走 `qq-chat-v2`。

## 2. 模块速查表

| 模块 | 一句话 | 什么时候最能感觉到 |
| --- | --- | --- |
| 注意力 | 决定这条要不要接、对谁说 | 群里没人叫 bot 时，回复明显变少 |
| 记忆 | 把值得留的事沉淀下来，下次带进提示词 | 隔天还能接上昨天的话题 |
| 节奏 | 多条消息之间的打字间隔 | 回复不再“啪啪啪”瞬间刷完 |
| 风格 | 检测并轻改 AI 味 | 少一些“总的来说/首先其次最后” |
| 人设 | 定期把人设锚点重新注入，防漂移 | 长对话后仍保持同一说话风格 |
| 情感 | 给回复加一点点情绪惯性 | 被夸时更活跃，被骂时更收敛 |
| 主动性 | 在合适的时候主动开口，且不刷屏 | 冷场时偶尔起话题，深夜不打扰 |
| 表情 | 按语境挑表情，没有合适的就不发 | 不再随机甩一张不相关的表情 |

---

## 3. 注意力（attention）

**作用**：每次唤醒先判断这条消息值不值得接、是不是在叫 bot、要不要再等等。它是三代里行为改变最大的模块。

**怎么判断**：

- 私聊、@bot、引用 bot、叫 bot 名字、主人消息、直接提问、拍一拍 → **一律进入生成**（硬规则，不允许被判成沉默）。
- 群聊里没人叫 bot → 按 `salience` 打分：
  `受话人权重 + 话题相关 + 关系分 + 紧急度 - 抢话惩罚 - 刚发言惩罚`。
- 分数 ≥ `发言阈值` → 说；介于两阈值之间 → 等；低于 `沉默阈值` → 沉默并写 trace。
- 连续沉默达到阈值只**告警/触发重新评估**，不会“沉默 5 次就硬说一句”。
- 拍一拍有冷却，冷却期内重复拍不会反复唤醒。

**关键参数（默认）**：发言阈值 `0.55`、沉默阈值 `0.25`、连续沉默提醒 `5`、拍一拍冷却 `60000ms`。

**例子**：

- 群里有人发「今天好热啊」，没 @ 任何人，bot 30 秒前刚说过话 → 分数低于 0.25 → **沉默**，不回复，只记 trace。
- 同一条改成「@bot 今天好热啊」→ 命中直接提及 → **立即进入生成**，不受阈值影响。
- 私聊里说「在吗」→ 私聊是硬规则 → **必回**（除非权限/静默/安全拦截）。

**注意**：注意力不是“每条都必须回”，它的目标恰恰是让 bot 学会不接无关闲聊。灰度初期如果觉得它太安静，可以先关掉这个模块，只开节奏/风格。

## 4. 记忆（memory）

**作用**：把二代会话里的“进行中话题 / 群友印象”沉淀成三代长期记忆；下次唤醒时按相关度取前几条，并入【长期记忆】子块。

**怎么工作**：

- 二代的 `activeTopic`（进行中话题）→ 三代 **episode 情景记忆**，默认 24 小时有效。
- 二代的 `memberImpression`（群友印象）→ 三代 **relationship 关系档案**，长期保留，可被新印象覆盖（旧条目保留审计）。
- `pendingThought`（bot 自己的念头）**不沉淀**；主人私聊里的自动话题也不沉淀（避免把“我说了什么”当事实长期记住）。
- 群聊来源默认 `candidate`（候选可信），私聊来源 `observed`，敏感事实（联系方式/地址/行程/健康/财务）需要主人确认才能跨会话检索。
- 每天 `04:30` 巩固一次：重复情景升格为事实、矛盾事实用 `supersededBy` 覆盖旧值、过期条目归档。
- 注入有上限：最多 `12` 条 / `1800` 字，按相关度 + 重要度 + 新近度裁剪。

**例子**：

- 群里小明连续几次聊手冲咖啡 → 形成关系档案「小明：手冲很讲究、话不多」。
- 第二天小明说「今天又翻车了」→ 检索到这条关系档案 → 回复能自然接上「又手冲翻车了？」。
- 某个话题（例如「周末搬家」）24 小时内有效；过了时效自动归档，不会一直挂在提示词里。

**注意**：

- 勾着「记忆只读锁」时，记忆模块**完全不工作**：不写、不注入、不巩固。想试长期记忆要取消勾选。
- 记忆不是聊天记录全量备份，只留可长期成立的部分；群里不会展示「我记得你说过……」这类系统腔。

## 5. 节奏（rhythm）

**作用**：模型一次给出多条气泡时，决定第 2 条及以后每条之间等多久，让回复像人在打字，而不是瞬间刷屏。

**怎么工作**：

- **首条永远立即发**，不加思考延迟。
- 后续每条间隔 ≈ 思考时间（200~800ms）+ 按上一条字数估算的打字时间 + 少量犹豫。
- 打字速度 `40~100 字/分`（关系越熟越快，深夜稍慢）。
- 单条间隔钳在 `300~5000ms`，整轮累计不超过 `5000ms`。
- 单轮最多 `5` 泡；超过时把多余内容合并进最后一泡，**不丢内容**。
- 只影响 `auto` 间隔；模型显式指定 `fixed` / `byLength` 时仍走二代原逻辑。

**例子**：

- 模型想发三条：「今天降温了」「记得穿外套」「别又感冒了」。
- 第 1 条立即发；第 2 条约 1.5 秒后；第 3 条约 2 秒后；整轮合计不超过 5 秒。
- 如果模型一次给了 8 条，会合并成 5 条再发，而不是硬砍掉后 3 条。

**注意**：私聊/@/主人/直接提问仍走快速档；节奏不会给首条加延迟，也不会伪造“正在输入”。

## 6. 风格（style）

**作用**：本地规则检测 AI 味，命中高置信度问题时做**一次**轻改；不改事实、数字、链接、承诺、称呼。

**会检测什么**：禁词/客服腔、八股结构（首先其次最后、一方面另一方面）、三连排比、句长方差过低、感叹号/问号密度异常、表情堆叠、过长的解释性段落。

**怎么处理**：

- 只对高置信度（≥0.8）的问题动手；
- 严肃/哀悼/医疗/法律等敏感话题直接放行；
- 改写最多一次，超过 `2000ms` 直接发原稿；
- 低置信度只记录 `style_flag`，不强行改。

**例子**：

- 生成：「总的来说，这个问题可以从三个方面来看：首先……其次……最后……」
- 命中八股结构 → 轻改为：「这事我说不好，得看你想花多少钱、多少时间，别的都好说。」
- 如果改写超时或话题是「家里老人住院了」→ **原稿直接发**，不卖萌、不改写。

**注意**：它只处理“怎么说”，不处理“说什么”；不会插入随机语气词，也不会改变称呼和关系。

## 7. 人设（persona）

**作用**：防止长对话后人格漂移。把「名字/身份/说话特征/红线/关系称呼」压成一段短锚点，按节奏重新注入。

**怎么工作**：

- 首轮必锚；之后每 `10` 轮唤醒重锚一次；
- 如果最近 10 条 bot 发言持续偏离基线（句长/标点/语气词/表情 + 自称 AI + 红线词），连续 `2` 轮漂移 → 触发强锚 + 告警；
- 锚点附加文本受 `500` 字预算限制，超了按「关系 → 红线 → 说话特征」的顺序丢段，单段仍超才硬截断；
- 漂移监测**只告警和重锚，不自动改人格**；人格文件仍只由主人编辑。

**例子**：

- 平时唤醒只带基础身份段，不堆长文。
- 第 10 轮唤醒时补上：「说话特征：元气、不说教；红线：不冒充真人、不泄露隐私；称呼：主人/小明」。
- 如果最近 bot 开始说「作为 AI 助手，我建议您……」→ 判定自称 AI + 风格偏离 → 记漂移，下一轮重锚提醒回角色。

**注意**：控制台里的「说话特征」「红线/禁忌」为空时，锚点只剩红线和称呼；填 3~5 条短语效果最好。

---

## 8. 情感（affect）

**作用**：给 bot 一个很轻的情绪惯性（PAD：愉悦/唤醒/掌控感），只用来微调表达，不覆盖事实和权限。

**怎么工作**：

- 快变量：本轮事件（好消息/坏消息/被夸/被怼/被忽视/尴尬）产生一个小增量；
- 慢变量：向基线缓慢回归，默认 `6` 小时回撤；
- 只调制：句长、延迟、表情率、主动概率、插话倾向；
- 调制幅度默认 `0.3`，所有乘数钳在 `[0.8, 1.2]`，不会大起大落。

**例子**：

- 主人说「好消息，我中奖了」→ 判为好消息 → 愉悦和唤醒上升 → 回复稍长、延迟稍短、主动概率略高；
- 几小时后自然回落到基线，不会一直亢奋。
- 被人怼 → 愉悦下降、唤醒上升 → 回复变短、变收敛，但**不会改变权限、不会拒绝该回的消息**。

**注意**：情绪只影响“语气和节奏”，不改变事实、不改变白名单、不改变工具权限；重启后状态归零。

---

## 9. 主动性（proactive）

**作用**：在群里安静时偶尔主动开口，但带作息、打扰预算和冷却，避免刷存在感。

**怎么工作**：

- 作息闸：默认 `23:00~08:00` 深夜不主动；@/私聊/主人/明确提问例外。
- 可打断分数：对方是否活跃、群是否多人连续聊、bot 刚说过话、话题是否与 bot 相关、对方回复延迟（平台没有就记 0，不伪造）；低于 `0.3` 不主动。
- 预算：每群每天最多 `3` 次、每人每天最多 `1` 次；同目标冷却 `90` 分钟。
- 连续主动没人接 → 冷却按 `backoff` 拉长（最多 4 倍），降频但不会永久归零。
- 未尽话题：从「承诺/考试/生病/出行」里抽取，到期跟进，最多 `2` 次；没人接就放下，不反复追问。
- 二代原有的主动概率判定仍然先跑，三代预算是在它之后再加一道闸。

**例子**：

- 凌晨 2 点群里很安静 → 深夜闸直接拦住，不主动。
- 下午 3 点群里安静，可打断分数 0.42、群预算还有 → 可能主动起一个话题；
- 同一个人今天已经被主动找过 1 次 → 每人预算用完，跳过。
- 小明昨天说「我明天期末考试」→ 24 小时后到期跟进一次；如果没回应，最多再试一次就放下。

**注意**：`@`、私聊、主人、明确提问不受深夜和预算限制（这些属于“回应”，不算主动打扰）。

---

## 10. 表情（sticker）

**作用**：按当前语境给表情打分，挑最合适的一张；没有合适的就**不发**，不随便凑数。

**怎么工作**：

- 语境来源：最近几条对方消息的情绪 + 当前 PAD 情感；
- 打分：标签匹配（Jaccard）+ 历史反馈（好用/不好用）+ 新近惩罚；
- 取 top-`3`；top-1 低于 `0.3` 视为「无合适」；
- 同一张表情 `24` 小时内用过 → 分数 ×0.7，防止一张图刷屏；
- 发送后可以在控制台回填「好用/不好用」，下次排序会参考。

**例子**：

- 对方说「笑死我了」→ 语境判为开心/高唤醒 → 候选里「笑/开心」标签的表情得分 0.62 → 发送。
- 如果所有候选都低于 0.3 → **不发表情**；调用方允许跳过时直接跳过，不允许时才回落到二代随机挑选。
- 同一张表情一小时前刚发过 → 分数 ×0.7，可能被另一张更合适的反超。

**注意**：表情模块不会偷换模型已经选好的图（合格就放行）；它只负责“合不合适”和“要不要发”。

## 11. 建议的开启顺序

第一次灰度不建议 8 个模块一次全开。行为变化从轻到重，建议：

1. **先私聊 canary，只开「节奏 + 风格」**：几乎只改表达，风险最低。
2. 稳定后加 **人设 + 情感**：只影响提示词和轻微语调。
3. 再加 **注意力**：观察是否漏回直接提及、是否过于安静。
4. 再加 **主动性**：观察是否打扰、是否被群友反感。
5. 最后开 **记忆**（取消记忆只读锁）：确认长期记忆确实有用、没有记错事。

每一步观察 1~2 天，看控制台和 `state/simulation-trace-*.jsonl` 的决策记录，再决定下一步。

## 12. 常见误区

| 误区 | 实际 |
| --- | --- |
| 模块勾上了就生效 | 还要过「总开关 → 灰度模式 → 群名单」三道门 |
| 灰度模式选 `on` 就是全量 | `on` 仍要求 canary 名单，空名单 = 全部走二代 |
| shadow 没运行 | shadow 在算，只是只记录、不改行为 |
| 记忆只读锁是总锁 | 它只锁记忆模块，节奏/风格/注意力不受影响 |
| 注意力会让 bot 每条都回 | 恰恰相反，它会过滤没人叫 bot 的群聊 |
| 情感会让 bot 情绪化 | 调制幅度默认 0.3，乘数钳在 0.8~1.2，只影响语气 |
| 人设会自己改人格 | 只告警和重锚，人格文件仍只由主人编辑 |
| 表情模块会乱发表情 | 没有合适的不发，且同一张有复用冷却 |

## 13. 一句话记住每个模块

- **注意力**：该不该接。
- **记忆**：值不值得记。
- **节奏**：像不像人在打字。
- **风格**：像不像客服/AI。
- **人设**：还是不是同一个人。
- **情感**：今天心情怎么样。
- **主动性**：现在适不适合开口。
- **表情**：这张图配不配这句话。
